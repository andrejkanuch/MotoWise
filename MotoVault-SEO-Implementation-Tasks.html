SEO-001 Verify Google Search Console & Request Indexing
SEOAnalytics

The site has a verification file (public/google2cfdfd4cab394901.html) but may not be fully verified or indexed. Log into GSC, confirm verification, inspect the homepage URL, and manually request indexing for all key pages.

  • Log into Google Search Console and verify motovault.app ownership
  • Submit https://motovault.app/sitemap.xml in GSC → Sitemaps
  • Use "URL Inspection" to request indexing for: /, /blog, /features/ai-diagnostics, /features/learning-paths, /features/garage-management, /features/progress-tracking
  • Check "Coverage" report for any crawl errors, excluded pages, or indexing issues
  • If using Vercel: verify that ISR/SSR is serving fully rendered HTML to Googlebot (test with "View Rendered Page" in GSC)
Impact: 🔴 CRITICAL — Nothing ranks until Google can see the site. This unblocks everything.
SEO-002 Audit CSP Headers for Googlebot Compatibility
WebSEO

The strict CSP in apps/web/next.config.ts may block Googlebot from rendering the page properly. Googlebot needs to execute JS and load resources — overly restrictive CSP can cause blank-page rendering.

  • In GSC's URL Inspection, click "View Rendered Page" to see what Googlebot sees
  • If the page renders blank/broken: audit the CSP script-src and connect-src directives in next.config.ts
  • Ensure Vercel Analytics, fonts (Google Fonts), and any required CDNs are whitelisted
  • Test with Lighthouse and Google's Mobile-Friendly Test tool
Depends on: SEO-001

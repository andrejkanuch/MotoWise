# Lens it2 — /layout (arrange): rhythm, grouping, guardrails, alignment, overflow

Scope: every file in `lens/SCOPE.md`. Method: source read of the page files and their CSS, `curl` of the dev server for DOM order, and `impeccable detect --scope layout` run against `/`, `/compare`, `/features/maintenance`, `/explore`, `/pro`, `/blog`, `/tools/cost-calculator` at 1280×800 and 390×844 (the detector only fires on rendered pages; it reported `line-length` on `/`, `/features/maintenance` and `/tools/cost-calculator` and nothing else). Paths below are relative to `apps/web/src`. Spacing scale used for "off-scale": 4/8/16/24/32/48/64/96/120/160; 40 is treated as a tolerated half-step because it carries the breadcrumb and navbar gutters everywhere, and 12/20/28 are only flagged where they break a group.

## Summary

The Trackside pages are structurally sound: every list is a hairline list, card budgets hold on almost every section, phone frames are one per page, tables all have a scroll wrapper, and the Persuade pages open with what / why / what-to-do. The problems are second-order and systemic rather than per-page accidents:

1. **Rhythm is flat on the two template families.** Every section of a feature page is `120px / 120px`; every section of a compare page is `pt-20 md:pt-28` (80 / 112). Nothing is tight, nothing is generous, so the deeper-band alternation does all the work. On the home page the problem is the opposite: two consecutive `100svh` sections at the top (hero, manifesto) with a 13px orphan paragraph between them, and a trips panel that lands on the proof hairline with 0px of air.
2. **There is no single container.** The navbar has no inner `max-width` (its logo drifts left of the content on anything wider than 1320px), the compare family uses 1040/1160 with 24px gutters, the read/index shells use 24px gutters at desktop, welcome uses 1200/48, the 404 uses 72px, the cookie bar 20px, the garage 48px against a 32px nav. Only `.mv-section*`, `.fx-container`, `.xp-wrap`, `.rh-inner`/`.rsec` and `.mvp-section` share the 1240/40 edge.
3. **Row grammar has eleven heights.** Hairline rows use paddings of 12/13/14/16/18/20/22/24/26/28/32px across the site (and three different ones on a single feature page), so the one shared device, "a row between hairlines", does not read as one device.
4. **Stat-row and identical-grid guardrails are bent, not broken.** The home page shows two figures under each of its four feature blocks plus the proof row; the compare family repeats a 2×2 bordered tile grid on three pages; the home page uses the same deeper-band-with-cut-screen composition twice (rides, diagnostics).
5. **Reading measure escapes on the long-form prose.** Feature-page long-form paragraphs run ~110 characters (820px column, no `max-width` on the paragraph); the home FAQ answers run ~95; `.mv-read-body` at `70ch` renders ~90 real characters with the system face.

Guardrail violations found: **9** (listed with ★/rows below). Highest-impact fixes are marked ★ (10).

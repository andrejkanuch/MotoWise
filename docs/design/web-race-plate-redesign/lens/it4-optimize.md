### Order of work (by bytes saved per page view)
1. Pick namespaces in every `NextIntlClientProvider` (−97 KB gz HTML, every page).
2. Move the hero preloads into `hero.tsx` (−226–292 KB on every non-home marketing page).
3. Dynamic-import Supabase in navbar + identity (−64 KB gz JS, every page).
4. Lazy Sentry Replay + posthog no-external (−60–80 KB gz JS, every page).
5. Fonts: Jakarta → piel, Geist Mono → system mono (−99 KB, −2 preloads, every page).
6. Hero JPG → AVIF/WebP `<picture>` with `srcset` (LCP bytes −60–80 % on `/`).

# it2 · /clarify lens — UX copy audit (research only, nothing edited)

Scope: every en.json key loaded by in-scope code (`SCOPE.md`) plus the hardcoded English of the root-only routes. Voice contract: DIRECTION.md "Voice" + BUILD-BRIEF.md "Voice" + PRODUCT.md (never invented proof, prices never hardcoded, logging is always free, no gamification, no hype).

Method. (1) Mapped each en.json namespace to the files that call `getTranslations`/`useTranslations` (incl. `namespace:` props on `FeatureContentPage`/`VsComparePage`) and matched every leaf key against literal and template `t()` calls, resolving `${key}`/`${i}` from the page's `*_KEYS`/`*_INDEXES` constants. 2,772 leaves → 2,088 live, **684 dead** (24 %). (2) Pattern-scanned live copy for Title Case, hype words, proof numbers, price literals, generic labels, `!`/emoji. (3) Read the root-only routes in full. Product truth checked against `packages/types/src/constants/limits.ts` (free = 1 bike, 1 AI scan, 3 receipt scans, 1 GPX export, 2 articles, 3 trip questions, 2 ride summaries a month), `packages/types/src/validators/trip.ts` (12 waypoint types incl. start/end), `apps/web/src/lib/pro-plan.ts`, `apps/web/src/lib/web-pricing.ts`, and a grep of `apps/mobile/src` (no turn-by-turn navigation, no maintenance-report export).

Terminology used below (product definitions): **ride** = recorded GPS; **trip** = a planned, multi-day plan; **route** = a curated public route in Explore; **service** = a logged maintenance job; **expense** = a logged cost.

Counts: ★ top 20 · (a) 62 en.json rows · (b) 35 root-only rows · (c) 18 prune rows covering 684 keys in 41 namespaces · (d) 15 owner flags. 150 rows in all.

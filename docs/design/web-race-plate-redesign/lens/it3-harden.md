# Harden lens — iteration 3 (research only, nothing edited)

Scope: `docs/design/web-race-plate-redesign/lens/SCOPE.md`. Method: source read of every in-scope file, `curl` of the rendered DOM on `http://localhost:3000` (dev server, `x-nextjs-prerender: 1`), `messages/*.json` diffed against `en.json`, contrast computed from `packages/design-system/src/mv-tokens.css`. No browser pane. Severity: **blocker** (broken for a real class of visitor) · **major** (wrong state or layout under a common input) · **minor**. ★ = the 10 most critical.

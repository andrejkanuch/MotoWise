# #365 board: Skeptic's final verdicts

2026-11-12. Read: the evidence pack, the six persona files (final drafts, including "Answers to review"), and my own review files from rounds 1 and 2.
I did no new research. I ran one read-only check against the production database, because P05.2 rests on it (below). Nothing else was written anywhere.

**Scale:** STRONG = sourced, measurable at ~7 installs a day, and within the hard constraints. PLAUSIBLE = reasonable, but the effect or a key mechanism is unbacked, or the file still conflicts with the board's recorded decision. WEAK = unbacked or unmeasurable, or withdrawn or parked with nothing left to ship.

**One check I ran myself** [SOURCE: Supabase prod, read-only SELECT, 2026-11-12]. This checks P05.2's premise: the first bike was created within a day of sign-up, and it has a maintenance task within a day of the bike. Results: Aug 14–Sep 30, **107 of 161**; Oct 1–Nov 4, **44 of 127** (35 of those bikes have no model). 05 reported 105/161 and 45/127. **The October drop in schedule import is real.**

## What has to be settled before anything ships

1. **The single decision.** 06 recorded the bundle (P01.1/P02.1/P02.2/P03.1/P03.2/P05.1, with P01.2/P04.1 as the fallback) in the P06.2 slot, assigned at all completers, primary week-1 core action 61/367. The text in 03 (P03.1 "Ships when"), 04 (supports option b) and 05 (P05.1 on the P06.3 path) still argues otherwise. The owner signs the ledger, and those lines become void.
2. **One spec, not four.** One sheet string with both conditions (02/03's, not the "moved more than 50 m" in 01/05), one notification kind (`activation_next_ride` or `activation`), one plan event (`first_ride_plan_set` or `next_ride_plan_set`), one variant value (`teaching`), and one button order.
3. **#365's "done when".** The day-1 funnel exists (pack §2). The board delivers **one** concrete randomized experiment (the bundle) with a target metric: week-1 core action among completers, 61/367, with day-2 engaged return 37/367 as the secondary. The honest second candidate is **not** a lift test: the October schedule-import fix (P05.2 step 5), read on "day-0 bikes with tasks" (44/127 since October). It fixes a verified break in what the web promises.
4. **Expectations.** Every sourced effect for these mechanisms is small (d = 0.27, RR 1.039, +2% in Duolingo's study). A capped "no winner" in March is the most likely outcome, and it must be read as "no doubling shown", not as a failure of the idea.
